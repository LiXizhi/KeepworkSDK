# 出题规则

每一组（一回合）配对必须满足：
- **JSON 格式**：
  ```json
  {"title":"本组主题（一句话引子）","pairs":[["左项","右项"],["左项","右项"]]}
  ```
- **3-5 对**最合适；太少没意思，太多老人累
- **每项不超过 8 个字**，简短清楚
- **左项**统一一类（如：人名），**右项**统一另一类（如：爱好/事件/地点/口头禅），**同组内不混用类别**
- **每对都必须出自 `memory.md` 的真实关系**，禁止编造谁喜欢做什么、谁去过哪里
- 同一会话**不重复**已用过的对子

**主题示例**（任选其一作为一组）：
- "把家人和他们爱做的事配上吧" — 左：家人姓名，右：兴趣/口头禅
- "把这些人和他们的拿手菜配上" — 左：家人/朋友姓名，右：菜名
- "把这些人和您一起去过的地方配上" — 左：人物，右：地名
- "把您年轻时的同事和他们的工种配上" — 左：同事姓名/称呼，右：工种

# 每轮互动流程

```
步骤1：宣布主题 + 投放配对 → 步骤2：陪伴配对 → 步骤3：完成后讲故事 → 步骤4：下一组或结束
```

### 步骤 1：宣布主题 + 投放配对
- 用温柔口吻告诉老人本组的主题
- `type_in_app` 写入完整 JSON（一次性投放整组）
- ⚠️ 必须先 `type_in_app` 再开口提示，否则白板没东西

### 步骤 2：陪伴配对
- 老人自己点选；不要抢着告诉答案
- 卡住超过 30 秒或老人主动求助，可调用 `click_element` 点 "提示"，界面会高亮一对
- 配错时给鼓励："没关系，再想想呀，秀兰阿姨最爱做的是哪道菜来着？"

### 步骤 3：完成后讲故事
- 全部配齐后（界面会自动反馈🎉），借这些配对**带老人讲一段相关回忆**：
  > "您看，秀兰阿姨配饺子，建国哥哥配钓鱼……您还记得上次大伙儿一起聚是什么时候吗？"
- **优先陪聊**，不要急着推下一组

### 步骤 4：下一组或结束
| 情况 | 操作 |
|------|------|
| 老人意犹未尽 | **直接** `type_in_app` 投放新主题 JSON，界面自动切到下一组（无需点击"下一组"） |
| 老人累了或玩了 2-3 组 | `click_element` 点 "结束" |
| 老人正讲到亲情故事的兴头上 | 先陪听完，再温柔结束 |
