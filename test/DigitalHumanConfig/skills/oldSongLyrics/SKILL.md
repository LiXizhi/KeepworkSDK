# 选歌规则

**首要原则：选老人年轻时代（约 15-30 岁）流行的歌**。这个时代窗口由 `memory.md` 中的出生年份/年代信息推算：
- 1940s 生人 → 1950s-70s 革命歌曲、戏曲选段、《东方红》《社会主义好》《我的祖国》《让我们荡起双桨》《北京的金山上》等
- 1950s 生人 → 1960s-80s 经典：《九九艳阳天》《年轻的朋友来相会》《我们的生活充满阳光》《在那桃花盛开的地方》
- 1960s 生人 → 1980s-90s：邓丽君、《妹妹找哥泪花流》《我的中国心》《十五的月亮》《血染的风采》《敢问路在何方》《一无所有》
- 1970s 生人 → 1990s-2000s：《同桌的你》《小芳》《心太软》《朋友》《雾里看花》

**优先级**：
1. 如果 `memory.md` 中**明确提到**老人爱听某首歌或某位歌手，**首选**那一首
2. 否则按出生年代选公认经典
3. 戏曲爱好者（记忆中提到京剧/越剧/黄梅戏等）可以选戏曲名段

# 出题 JSON 格式

```json
{
  "songTitle": "歌名",
  "line": "完整的一句歌词",
  "blank": "要被挖空的几个字（必须是line的子串，通常2-4字）",
  "hint": "可选的轻提示"
}
```

要求：
- `line` 选歌中**最有名、传唱度最高**的那一句
- `blank` 通常挖**句尾**或**关键名词**（地名、人名、关键意象），让老人有"接下去"的感觉
- `blank` 必须是 `line` 中真实出现的子串（界面靠 `line.indexOf(blank)` 做替换）
- `hint` 是温柔的提示，不要直接说出答案。例：`"是个开国领袖的名字"`、`"红色的什么花呀？"`

**示例**：
- `{"songTitle":"东方红","line":"东方红，太阳升，中国出了个毛泽东","blank":"毛泽东","hint":"那位最伟大的领袖呀"}`
- `{"songTitle":"年轻的朋友来相会","line":"年轻的朋友们今天来相会，荡起小船儿暖风轻轻吹","blank":"暖风轻轻吹","hint":"船儿一荡，风是怎么吹的呀？"}`
- `{"songTitle":"在那桃花盛开的地方","line":"在那桃花盛开的地方，有我可爱的家乡","blank":"我可爱的家乡","hint":"那是您心里最暖的那个词"}`

# 每轮互动流程

```
步骤1：投放歌词 → 步骤2：哼一句 / 等老人接 → 步骤3：揭晓 + 闲聊 → 步骤4：下一首
```

### 步骤 1：投放歌词
- `type_in_app` 写入完整 JSON
- 把已显示的部分**温柔地念/哼**出来，到空格处停下："东方红，太阳升，中国出了个 ……？"

### 步骤 2：等老人接
- 老人接词时不要打断
- 接不上：可以再哼前两个字给提示，或者口述 `hint`

### 步骤 3：揭晓 + 闲聊
| 情况 | 操作 |
|------|------|
| ✅ 接对了 | 喝彩 → `click_element` 点 "答对了"（界面会自动揭晓答案） |
| ⚠️ 接得近似 | "差不多啦～" → 点 "答对了" |
| ❌ 接不上 | "我帮您把后半句唱出来啊——" → `click_element` 点 "揭晓" |

之后**追问一两句**："这首歌是不是您和老伴儿那个年代特别流行的呀？""您还记得最早是在哪儿听到的吗？"

### 步骤 4：下一首
- **直接** `type_in_app` 投放新歌 JSON，界面自动切到下一首
- ⚠️ **无需** `click_element` 点"下一首"，直接写入新 JSON 即可
- 歌曲数量由 `type_in_app` 调用次数决定

# 结束条件

每接 2-3 首后询问是否继续。`click_element` 点 "结束" 当：
- 老人累了或主动想停
- 已接 3-5 首
- 老人开始大段讲那个年代的故事——优先陪听
