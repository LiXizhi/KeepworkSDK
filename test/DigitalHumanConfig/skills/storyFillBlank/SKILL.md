# 任务目标

通过"故事填空"小游戏，AI 用一段简短的话**复述老人记忆中的某个真实故事**，把其中**一个关键细节**（一个名字、一道菜、一个地名、一个年份）替换成 "______"，让老人来填。锻炼**叙事性记忆**而不是孤立事实。

使用"问答白板" App，老人语音作答。

# 出题规则

每题必须满足：
- **故事主体**严格来自 `memory.md`（首选）或当月 `memory/YYYY-MM.md`，**不可编造情节**
- **简短**：1-2 句话，30-60 字最佳，太长老人不容易抓住空格在哪
- **空格只挖一个**：人名 / 地名 / 食物 / 数字 / 时间四类细节优先
- **空格用 "______" 表示**（6 个下划线），其余信息保持完整以提供上下文
- 同一会话**不重复**已用过的故事；同一故事尽量只挖一次空

题面格式（写到白板上的内容）：
```
您给我讲过：1985 年您从 ______ 老家来到上海，就在火车站对面的小旅馆住了第一晚。
请把空格里的地名告诉我吧～
```

# 每轮互动流程

```
步骤1：投放故事 → 步骤2：等老人填 → 步骤3：判定反馈 → 步骤4：顺势追问 → 步骤5：下一题
```

### 步骤 1：投放故事
- `type_in_app` 把整段故事（含 "______"）写到白板上
- 同时温柔地朗读一遍，最后强调"空格里是哪个字呀？"

### 步骤 2：等老人填
- 老人想不起来时，给**一字线索**（"是个'淮'字开头的地名哦"），不要直接说

### 步骤 3：判定反馈
| 情况 | 操作 |
|------|------|
| ✅ 答对（含同义/近似） | 口头表扬 → `click_element` 点 "答对了"计分 |
| ⚠️ 答得接近 | "差一点儿啦，是 XX 哦"→ `click_element` 点 "答对了"（不打击信心） |
| ❌ 完全想不起来 | 温柔告知 |

### 步骤 4：顺势追问
- 围绕这个故事再聊一两句："那时候火车坐了多久呀？""第一晚紧张不？"
- 让老人有机会把整件事再讲一遍

### 步骤 5：下一题
- **直接** `type_in_app` 投放新故事，界面自动进入下一题
- ⚠️ **无需** `click_element` 点"下一题"，直接写入新内容即可
- 题目数量由 `type_in_app` 调用次数决定

# 结束条件

每填 2-3 题后询问是否继续。`click_element` 点 "结束" 当：
- 老人累了或主动想停
- 已填 3-5 题
- 老人开始讲与故事相关的长段回忆——优先陪听
