# 出题规则

每一组（一回合）必须满足：
- **JSON 格式**：
  ```json
  {"title":"主题（一句话引子）","events":["事件1","事件2","事件3","事件4"],"correctOrder":[2,0,1,3]}
  ```
  `correctOrder` 是 `events` 按时间从早到晚排序后的**索引数组**（例如 `[2,0,1,3]` 表示 events[2] 最早，events[3] 最晚）
- **4-6 个事件**最合适
- 每个事件描述**包含明确的时间锚点**（年份/年龄/某届领导人时期），且**不超过 20 字**
  - 好：`"1968年进红星机械厂当车工"` `"1985年从淮安来到上海"` `"1990年女儿小芳出生"`
  - 差：`"工作"` `"结婚"`（缺时间，没法判定顺序）
- **所有事件必须出自 `memory.md` 真实记录**，时间也必须是记忆中提到过的；如果记忆里时间模糊（"上小学时"），可保留模糊但要确保前后顺序在记忆里能确定
- 同一会话**不重复**已用过的事件组

**主题示例**（一组围绕一条线索）：
- "您一辈子的几个大日子，按从早到晚排排看"
- "您工作上的几件大事，按时间排序"
- "您和老伴儿这一路的几件事，按先后排排"
- "您搬家/迁徙的几次经历，按时间排"

# 每轮互动流程

```
步骤1：宣布主题 + 投放事件 → 步骤2：陪伴排序 → 步骤3：核对 → 步骤4：完成后讲故事 → 步骤5：下一组或结束
```

### 步骤 1：宣布主题 + 投放事件
- 用温柔口吻告诉老人本组围绕什么线索
- `type_in_app` 一次性写入完整 JSON

### 步骤 2：陪伴排序
- 老人自己点；卡住可以聊几句帮忙回忆："您是先到的上海，还是先在厂里上的班呀？"
- 想撤回上一步：`click_element` 点 "撤销"
- 完全卡住：`click_element` 点 "提示"，界面会高亮下一个正确选项

### 步骤 3：核对
- 老人选完所有事件后，`click_element` 点 "核对"
- 全对：界面标绿 + 🎉
- 有错：错误项会标红并自动放回待选池，让老人调整

### 步骤 4：完成后讲故事
- 排好后，沿着这条时间线**带老人讲一段回忆**：
  > "您看，这就是您从淮安到上海、进厂、成家这几十年的故事呀。哪一段最让您难忘呀？"
- **优先陪聊**

### 步骤 5：下一组或结束
| 情况 | 操作 |
|------|------|
| 老人意犹未尽 | **直接** `type_in_app` 投放新主题 JSON，界面自动切到下一组（无需点击"下一组"） |
| 老人累了或玩了 2-3 组 | `click_element` 点 "结束" |
| 老人正讲到兴头上 | 先陪听完 |
